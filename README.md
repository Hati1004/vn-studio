# 🌸 VN Studio 1.9 · 미연시 팝업 (SillyTavern 1.19)

채팅을 미연시 화면으로 보여 주는 확장이에요. 장소 배경, 표정, 의상, 호감도, 선택지, 이벤트 CG/영상이 대화에 맞춰 자동으로 나오고, 일상 모드·공략집·일정·캘린더가 있어요.
이미지·영상 생성부는 Scene Studio에서 가져왔고, Scene Studio의 장소·지도·이미 만든 장면 이미지와 연동돼요.

## 설치
1. 폴더를 `SillyTavern/data/<유저>/extensions/vn-studio/`에 넣거나 GitHub 주소로 설치해요. 새로고침 후 우측 하단 💗 버튼 또는 지팡이 메뉴로 열어요.
2. Scene Studio에 API 키가 있으면 **처음 한 번 자동으로 가져와요**. 없으면 확장 설정에서 입력하세요.

## 1.9.1에서 바뀐 것

- **선택지 안 보임 수정**: 스튜디오를 나갔다 들어오면 글상자를 접었다 펴야 선택지가 보이던 문제를 고쳤어요. 열 때와 선택지를 그릴 때 같은 레이아웃 재계산을 자동으로 하고, 선택지 애니메이션이 투명에서 시작하지 않게 바꿨어요.
- **카드·로어북으로 NPC 찾기**: NPC 탭의 새 버튼으로 캐릭터 카드와 로어북(파란 점 항목 우선)을 한 번 읽어서, 아직 마주치지 않은 인물도 미리 등록해요. 모델 1회 호출이에요.
- **표정 이미지 프롬프트에서 가방 문구 삭제**: 기본 표정 포즈의 "가방 끈을 잡고 있는" 문구를 뺐어요. 이미 만든 이미지는 그대로예요.
- **NPC 옆 이미지**: NPC가 말하거나 서술에 이름이 나오면 주인공 옆(첫 번째는 오른쪽, 두 번째는 왼쪽)에 같이 나타나요. 말하는 쪽이 밝아져요. 설정에서 이미지가 없는 NPC를 한 번 자동 생성하는 옵션도 켤 수 있어요(기본 꺼짐).

## 1.9에서 바뀐 것
- **지도 확대/축소**: 지도 위에서 마우스 휠, 오른쪽 위 **＋ / － / ⟲** 버튼, 모바일은 두 손가락 벌리기/오므리기로 확대·축소해요. 확대하면 지도를 끌어서 이동해요. 핀과 마커는 확대해도 같은 크기로 보이고, 지도를 바꾸면 처음 크기로 돌아와요.
- **마커는 아이콘만, 이름은 필요할 때만**: 이름표가 지도를 가리지 않도록 마커(NPC·캐릭터·나·적·퀘스트)를 핀 둘레의 작은 아이콘으로 바꿨어요. 아이콘에 마우스를 올리거나(모바일은 누르면) "NPC · 하나 (여관)"처럼 말풍선으로 이름이 떠요.
- **지도 이미지 비율 선택 삭제**: 지도 이미지는 정사각(1:1)으로 만들어요.
- **지도 이미지 기록**: 새로 만들거나 올려서 바뀐 이전 지도 이미지도 지워지지 않고, **배경 탭 → "지도 이미지"**에 모여요. 이미지를 누르면 크게 보이고, "이 지도로 쓰기"로 되돌리거나 "삭제"로 지울 수 있어요.
- **배경 탭에 지도 장소 표시**: 장소·마커 분석이나 지도 탭에서 만든 장소가 이미지가 없어도 배경 탭 목록에 나와요. 장소마다 "배경 생성"으로 미리 만들 수 있고, **"이미지 없는 장소 한꺼번에 생성"** 버튼으로 모아서 만들 수도 있어요(시작 전에 장수·요금을 알려 주고, 위쪽 "중지"로 멈출 수 있어요).
- **첫 배경 생성을 취소해도 막히지 않아요**: 배경 탭에서 장소를 "AI로 생성"으로 추가할 때 생성을 취소해도 장소는 목록에 남고, 나중에 "배경 생성"을 눌러 만들 수 있어요.

## 1.8에서 바뀐 것
- **지도 이미지 생성**: 지도 탭의 "내부 지도 정리" 옆에 **지도 이미지 생성** 버튼이 생겼어요. 지금 보고 있는 지도(세계 / 건물 내부)의 장소 위치에 맞춰 위에서 내려다본 지도 그림을 AI로 그려요(이미지 1회 요금). 글자·인물·핀은 그리지 않게 요청해요. 그림과 핀이 어긋나면 핀을 끌어서 맞추세요. 이미 있는 지도에는 "지도 이미지 다시 생성"으로 바뀌어요.
- **장소 아이콘**: 분홍 점 대신 장소 종류에 맞는 아이콘(🏠 집, 🏫 학교, 🛏️ 여관, ⚒️ 대장간, 🌳 숲 …)이 나와요. 종류가 "기타"이거나 비어 있으면 이름에서 짐작해요(침실·부엌·욕실·거실·정원·도서관 등).
- **NPC 위치 표시**: 마커(NPC·캐릭터·나·적·퀘스트)가 그 장소 핀 위에 이름표로 나와요. 방 안에 있으면 그 방이 속한 건물 핀에 붙고, 건물 내부 지도에서는 건물 자체에 있는 마커가 지도 위쪽에 모여요. NPC 이미지가 있으면 이름표에 작은 얼굴이 들어가요. 표시는 "마커 전체 / NPC만 / 마커 숨김"으로 고르세요.
- **NPC 위치 정하기**: 지도 탭의 "NPC 위치" 목록이나 NPC 탭의 "지도 위치"에서 장소를 고르면 돼요. "위치 없는 NPC 위치 찾기(모델 1회)"는 최근 대화·카드·로어북을 보고 위치가 없는 NPC만 채워요(이미 정한 위치는 건드리지 않아요). 마커 목록에서도 장소를 바꿀 수 있어요. 장면 생성기의 마커와 같은 데이터예요.
- 지도 이미지가 서버 이미지 정리("쓰지 않는 이미지 정리")에서 지워지지 않도록 보호해요.

## 1.7에서 바뀐 것
- **상태창 숨김 보강**: 중첩된 `<div>`(안쪽 닫는 태그가 남던 문제)를 짝 맞춰 통째로 지우고, 남은 태그는 모두 걷어 내요. `key: value`가 3줄 이상 이어지는 **YAML형 상태창**도 숨겨요(설정에서 끌 수 있어요). `[VN]` 블록은 이 숨김에 걸리지 않게 보호해요.
- **상태창만 따로 온 메시지**는 이야기로 치지 않아요. 채팅방에 처음 들어가도 마지막 *이야기* 답변이 보이고, 새로 온 상태창 메시지는 연출하지 않아요. 기록 패널의 "채팅 전체"에서도 빠져요(기록에 `</div>`와 공백이 보이던 문제도 같이 고쳤어요).
- **창을 닫은 사이에 온 답변 / 오래된 선택지**: 창이 닫혀 있는 동안 SillyTavern에서 새 답변이 오면, 다시 열 때 그 답변이 새 답변으로 나와요. 보던 장면이 최신이 아니면 최신으로 맞춰요.
- **선택지 아래 직접 입력칸**: "선택지 우선"을 없애고 "선택지 + 직접 입력 / 선택지만 / 직접 입력만"으로 정리했어요. 기존 "선택지 우선" 설정은 "선택지 + 직접 입력"으로 바뀌어요.
- **일상 모드 후속 선택지 개수**: 처음 선택지(3~4개)를 고르면 이어지는 선택지가 2~3개였던 건 의도한 설계(생성량 절약)였어요. 이제 설정에서 2~4개로 정하고, 모델에 정확히 그 개수를 요청해요.
- **일상 ↔ 채팅 분리**: 채팅 모드에서는 달력에 "오늘" 표시가 일상의 날짜로 남지 않고, 채팅 모드 이벤트는 일상 달력이 아니라 별도 목록에 쌓여요. 모드마다 장소·시간·날씨를 따로 기억해요.
- **HTML/CSS 효과 창**: 생각·본문·상태창 글·코드블록은 빼고 **효과(꾸며진 블록과 `<style>`)만** 보여 줘요. 제목 줄 없이, 마우스를 오른쪽 위에 올리면 이동·닫기 버튼이 나타나요. SillyTavern 페이지의 `@keyframes`/사용자 CSS도 함께 가져와요. 기록 패널의 "채팅 전체"에서도 효과가 있는 메시지는 격리해서 그대로 보여 줘요. 스크립트는 실행하지 않아요.
- **캐릭터 이미지 크기·위치**: 화면의 ⤢ 버튼(슬라이더), Ctrl+마우스 휠, 설정에서 조절해요.
- **테마 6종**: 벚꽃(기본)·한밤·숲·노을·라벤더·흑백 (설정 → 화면).
- **외형 추출 모델** 기본값을 `gemini-3.1-flash`로 바꿨어요(기존 `gemini-2.5-flash` 설정도 한 번 바뀌어요). 모델 이름을 쓸 수 없으면 `gemini-2.5-flash`로 대신 시도해요.
- **이벤트 씬 글씨 끄기**: 이벤트 화면 버튼으로 왼쪽 아래 제목·설명을 숨겨요(설정에 기억돼요).
- **선택지의 따옴표**: `"대사" 하고 웃는다`처럼 대사가 앞에 오는 선택지에서 첫 따옴표가 사라지던 문제를 고쳤어요(전체를 감싼 한 쌍일 때만 벗겨요).

## 1.6에서 바뀐 것
- **NPC AI 이미지의 외형 근거**: ① NPC에 저장된 외형 태그(편집 가능) → ② 없으면 설명 + 카드·로어북 + 채팅 기록에서 그 이름이 언급된 문장을 모아 모델 1회로 영어 태그를 만들어 저장 → ③ 근거가 전혀 없으면 태그 없이 "역할과 세계관에 맞게 설계"하도록 지시해요(매번 달라질 수 있으니 설명이나 태그를 적어 두세요). 생성 후 "외형 근거"가 알림으로 나와요. 메인 캐릭터 이미지는 화풍 참조로만 쓰여요.
- **선택지가 한두 개 안 보이던 문제**: 창이 숨겨진 동안 크기를 0으로 재서 작은 창 레이아웃이 남던 것을 고쳤고, 이제 글 영역이 줄어들고 선택지는 항상 전부 보이게 했어요.
- **일상 모드에서 "이벤트를 준비하는 중"이 멈추던 문제**: 모델 응답을 기다리는 최대 시간(기본 150초, 설정)을 두어 넘으면 이유와 함께 실패로 처리해요. "다시 시도"는 멈춘 요청을 버리고 새로 시작하고, 실패 이유는 화면과 호출 탭에 남아요.
- **이미지 삭제**: 목록에서 지울 때, 다른 곳에서 쓰지 않는 VN Studio 이미지(`user/images/vnstudio`)는 서버 파일도 함께 지워요(서버가 지원할 때만). 배경 제거 후 남던 원본도 정리해요. 설정 → 저장 공간의 "쓰지 않는 표정·NPC 이미지 찾아서 정리"로 이미 쌓인 것도 지울 수 있어요. 이벤트 CG/영상은 다른 채팅에서 쓰일 수 있어 자동 정리하지 않아요.
- **`<small><facts>…</small></facts>` 같은 프리셋 블록**: facts·infobox·charinfo·memo·tracker 등을 기본으로 숨겨요(태그 짝이 안 맞아도 처리). 설정의 "SillyTavern 채팅창에서도 숨기기"를 켜면 ST 채팅창에서도 화면에서만 가려요.
- **채팅 원본 서식 패널**: HTML/CSS가 있는 메시지가 오면 상단에 `</>` 버튼이 나타나요. 누르면 SillyTavern이 그린 메시지를 격리된 작은 창(끌어서 이동, 크기 조절)에 그대로 보여 줘서 색·CSS 애니메이션·진동·움직이는 이미지가 나와요. 스크립트(JS)는 보안상 실행하지 않아요. "자동으로 열기" 옵션도 있어요.

## 데이터가 어디에 남나
- 이미지 파일: `user/images/vnstudio/`. 확장을 삭제해도 남아 있어요.
- 표정·의상·배경 목록과 설정: SillyTavern `settings.json`의 확장 설정. 호감도·기록·이벤트·일상 계획·NPC: 각 채팅 파일. 확장만 지우고 다시 설치하면 이어져요(완전히 지우려면 폴더와 설정을 직접 지워야 해요).
- 정기 청소 없이도 느려지지 않아요. 기록은 최대 1200줄로 제한되고, 갤러리와 설정에는 이미지 주소만 저장돼요. 이미지 서버 저장이 실패해 그림 데이터가 설정에 직접 들어간 경우만 용량이 커질 수 있어요.

## 1.5에서 바뀐 것
- **외형 태그 추출을 장면 생성기와 같은 방식으로**: 같은 프롬프트(카드 설명 텍스트 → 영어 태그 한 줄)를 연결된 모델로 보내요. 이전에는 카드 PNG를 Gemini에 보내는 방식이 기본이어서 태그가 짧고 중간에 잘렸어요(생각 토큰이 출력 한도를 먹는 문제였어요). PNG 방식은 설정의 "카드 PNG 이미지도 함께 보내기"로 켤 수 있고, 켠 경우에도 잘림이 없도록 고쳤어요. 장면 생성기에 저장된 태그가 있으면 연동 상태에서 그걸 그대로 써요.
- **팝업이 저절로 뜨던 문제**: "캐릭터가 답하면 팝업 자동으로 열기"를 기본 꺼짐으로 바꿨어요(기존 설정도 한 번 꺼요). SillyTavern에서 채팅하거나 캐릭터를 눌러도 💗 버튼을 누르기 전에는 창이 뜨지 않아요.
- **캐릭터를 바꾸면 이전 캐릭터의 배경이 남던 문제**를 고쳤어요. 장면 생성기에서 지운 이미지도 이제 배경으로 쓰이지 않아요(갤러리에 실제로 있는 이미지만 사용).
- **호감도 하트 10칸**: 플러스는 빨간 하트가, 마이너스는 같은 10칸을 검은 하트가 채워요.
- **공략집 이미지 버튼**: 대표 이미지 바로 아래에 "이미지 바꾸기 / 내 이미지에서 고르기"가 나란히 있어요.
- **NPC 탭**을 공략집 옆에 따로 만들었어요. 이름·역할·설명·관계 요약·알아낸 정보를 직접 넣거나, "채팅 기록으로 분석(모델 1회)"으로 새 인물 찾기와 기존 인물 갱신을 한 번에 해요. 이미지 올리기/AI 생성/배경 제거도 같은 자리에서 해요.
- **배경 탭**(구 장소 탭): "+ 장소 추가"를 누르면 폼이 열려요. 이름·설명과 이미지 없음 / 올리기 / 장면 생성기 이미지에서 불러오기 / AI 생성 중에서 고를 수 있고, 기존 장소 카드에서도 장면 생성기 이미지를 불러올 수 있어요.
- **단색 배경 옵션**(설정 → 화면): 배경 이미지를 가리고 단색으로 채워요. 캐릭터 이미지에서 투명하게 안 지워진 부분(팔 사이 등)과 색을 맞춰 투명처럼 보이게 하고, 원본 이미지의 모서리 색을 자동으로 읽을 수도 있어요.
- **생성 취소 버튼**: 표정·의상 탭에서 이미지를 만드는 동안 작은 "생성 취소"가 나타나요(진행 중인 한 장은 끝까지 기다려요).
- **NPC 장면의 이벤트 CG**: 캐릭터가 없는 장면(NPC와 단둘이, 혼자)에서는 캐릭터를 그리지 않고 그 NPC(이미지가 있으면 참조)를 그려요.
- **한 카드에 여러 인물이 있을 때**: 표정·의상 탭에서 "카드 안의 다른 인물"을 등록하면 인물마다 외형 태그·표정·의상·호감도가 따로 관리돼요. 장면 생성기에 있는 인물은 눌러서 바로 추가할 수 있어요. 이야기에서는 모델이 [VN] 블록의 `who:`로 지금 보여 줄 인물을 알려 줘요. 카드 PNG에 여러 사람이 있어도 해당 인물만 그리도록 지시해요.
- **장소·마커 자동 분석**: 장면 생성기와 같은 분석(캐릭터 카드, 로어북, 최근 대화 → 장소와 마커)을 지도 탭 상단 박스에서 실행해요(모델 1회). 공략집의 "채팅 기록으로 분석" 아래 체크박스로 함께 실행할 수도 있어요(모델 +1회).

## 1.2에서 바뀐 것
- **429 방지**: 모든 이미지 요청이 한 줄 대기열로 한 장씩, 설정한 간격(기본 6초)으로 나가요. 429/503이 나면 20→45→90초 기다렸다가 자동 재시도해요.
- **이미지 호출 절약**: 의상은 직접 추가한 것만 써요(대화에서 새 옷이 나오면 "제안"으로만 모여요). 의상마다 기준 이미지 1장 → 필요하면 표정 6장(전체 10장은 선택) 순서예요. 자동 표정 생성은 기본 의상과 세트를 만들어 둔 의상에만 적용되고, 접속당 6장 상한이 있어요.
- **외형 일관성**: 처음 한 번 영어 외형 태그를 뽑아 저장해 모든 생성에 똑같이 쓰고, 항상 기준 이미지와 카드 이미지를 참조로 보내요. 표정 프롬프트에 자세·몸짓을 넣어 차렷 자세를 줄였어요.
- **이미지 크게 보기**: 표정·의상·공략집 이미지를 누르면 확대돼요.
- **페이드 연출**: 표정·배경은 천천히 디졸브되고, 시간대가 넘어갈 때는 암전과 함께 제목이 나와요(설정에서 속도 조절). 한 답글 안에서 표정이 여러 번 바뀔 수 있어요(`emo: a, b`).
- **시간·날씨**: 왼쪽 상단에 표시돼요. 채팅 모드는 모델이 알려 주고, 일상 모드는 하루 계획에 포함돼요.
- **능력치 삭제**. 일정은 활동 선택만 남았어요.
- **일상 계획이 이야기로 이어져요**: 이전 며칠의 사건과 이어질 이야기 줄기를 받아 매일 사건(갈등/비밀/사건/행사/NPC 등장)이 하나 이상 들어가요. 혼자 있는 시간에도 사건이나 NPC가 나오고, NPC와 단둘이 있는 장면도 생겨요. 등장인물은 공략집에 모여요.
- **기록 패널**: 상단 📜 버튼으로 옆에 띄워 두고 읽어요(좌/우 이동 가능). "연출 기록"(채팅·일상 모두 저장)과 "채팅 전체" 탭이 있어요. 글상자도 더 크게 보여요.
- **이벤트 씬**: 화면 중앙에 크게 띄워요. 장면 생성기가 새로 만든 장면 이미지(영상 포함)가 있으면 그것을 쓰고, 없으면 새로 만들어요. 발동 조건은 아래를 보세요.
- **호출 현황**: 왼쪽 상단 "API …" 칩과 ☰ → 호출 탭에서 누적·최근 호출을 볼 수 있어요.

## 이벤트 씬 발동 조건
① 모델이 답글에 `event:`를 넣을 때(최소 간격은 설정, 기본 4메시지) ② 호감도가 한 번에 ±4 이상 변하거나 하트 단계를 처음 넘을 때 ③ 일상 모드에서 특별 장면으로 표시된 장면 ④ 글상자 아래 **🎬 이 장면을 이벤트 씬으로** 버튼(언제든).
이벤트 씬은 기본적으로 이미지예요. 영상은 이벤트 화면의 버튼으로 만들거나, 설정에서 자동 변환을 켰을 때만 만들어져요.

## API 호출은 언제 나가나
- 채팅 모드: 메시지마다 추가 텍스트 호출 **0회**. 이미지는 새 장소 배경 1회(이후 재사용) / 없는 표정·의상 1장 / 이벤트 CG(장면 생성기 이미지가 있으면 0회)일 때만.
- 일상 모드: 하루 계획 1회 + 만남마다 1회 + 직접 입력할 때마다 1회. 선택지를 고르는 건 0회예요. 다음 만남은 첫 선택 직후 백그라운드에서 미리 만들어요.
- 그 외: 기존 채팅 분석 1회(처음 한 번), 외형 태그 추출 1회(캐릭터당 한 번).

## 동작 방식
모델이 답글 끝에 `[VN]` 블록(loc/emo/outfit/aff/info/event/선택지)을 붙이고, 확장이 읽어 연출한 뒤 채팅창에서 숨겨요. 추가 모델 호출은 없어요.

## 요금과 데이터
- 배경, 표정/의상, 이벤트 CG, 영상은 내 Google API 키로 요금이 발생해요. 표정 자동 생성은 접속당 상한(기본 14장)이 있어요.
- 일상 모드(계획 1회 + 만남 장면)와 기존 채팅 분석은 연결된 텍스트 모델을 써요. JSON을 잘 지키는 모델(Flash 이상)을 연결 프로필로 지정하는 걸 추천해요.
- 키는 `settings.json`에 평문으로 저장돼요. 이미지는 `user/images/vnstudio/`에 저장돼요.

## 문제 해결
| 증상 | 해결 |
|---|---|
| 표정·선택지가 안 나옴 | 설정 → "모델에 보내는 지시문 보기"로 켜져 있는지 확인. 프리셋이 맨 끝 지시를 무시하면 나오지 않을 수 있어요. |
| 글상자에 생각 내용이 보임 | 설정 → "글상자에서 숨길 태그"에 프리셋의 태그 이름을 적어 주세요. |
| 표정 이미지가 계속 같음 | API 키 확인 후 표정·의상 탭에서 세트를 만들어 보세요. 상한에 걸렸을 수도 있어요. |
| 429가 계속 뜸 | 설정 → "이미지 요청 간격"을 늘려 보세요 (기본 6초). 표정 세트는 6장 단위로 나눠 만드는 걸 추천해요. |
| 지도 탭이 비어 있음 | Scene Studio에서 이 채팅의 장소 분석을 먼저 해 주세요. |
| 일상 이벤트가 JSON 오류 | 연결 프로필 모델을 바꿔 보세요. 한 번 자동 재시도해요. |

## 알려진 한계
- 실제 SillyTavern에서의 확인이 필요한 부분: 지시문 주입(`setExtensionPrompt`), 표정 스프라이트 조회(`/api/sprites/get`), 표정 분류기(`/api/extra/classify`), `generateRaw`. 모두 실패해도 대체 경로로 넘어가요.
- AI로 만든 표정은 얼굴 일관성이 완벽하지 않을 수 있어요. 카드 이미지와 같은 의상의 기준 이미지를 참조로 보내 줄여요.
- 그룹 채팅은 말하는 캐릭터 중앙, 직전 화자 왼쪽(최대 2명)이에요.
